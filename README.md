# Prospect Previews

Micrositios conceptuales de rediseño web para prospección comercial de NexoDG.

## Arquitectura

- Next.js
- Un único proyecto de Vercel
- Rutas independientes por prospecto
- No indexado en buscadores
- Diseño responsive y reutilizable

## Previews iniciales

- /aoa
- /itepa
- /crip

Dominio previsto: `previews.nexodg.com`

## Criterio

El sistema no está limitado al sector industrial. La estructura se diseñó para incorporar prospectos de distintos nichos y luego medir cuáles obtienen mejor tasa de respuesta.
